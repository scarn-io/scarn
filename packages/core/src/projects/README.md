# Projects

This domain contains project-centric core business logic.

Responsibilities in this domain include project records, project membership and permissions, repository configuration, and project-scoped defaults or configuration seeded for a project.

Current entities in this domain include the `project` entity and its related application services, contracts, domain events, and persistence adapters.

Do not place pipeline definitions, pipeline execution state, work item records, or agent/runtime session execution records in this domain.
