The catalog is a growing collection of interactive examples — real Scarn building blocks rendered directly on the page, not screenshots or static diagrams. Each entry shows one concept in action, alongside the fixture that produced it.

- [Pipeline Graph](/scarn/catalog/pipeline-graph/) — a pipeline JSON document's node/edge graph, rendered with the same React Flow view used by `scarn pipelines studio`.
