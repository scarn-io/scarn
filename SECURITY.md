# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: open
the [Security tab](https://github.com/scarn-io/scarn/security) of
`scarn-io/scarn` and choose **Report a vulnerability**, or go straight to
[the advisory form](https://github.com/scarn-io/scarn/security/advisories/new).

Include what you can of:

- the affected component (API, web app, CLI, worker, SDK, self-host setup)
  and version or commit,
- steps to reproduce, or a proof of concept,
- the impact you expect.

We'll acknowledge the report, keep you updated while we work on a fix, and
credit you in the advisory unless you'd rather stay anonymous.

## Supported versions

Fixes go into the latest release. Security fixes are always released to the
open-source version, for both the hosted service and self-hosted installs.
If you self-host, upgrade to the latest release to pick them up.
